# Yug Amin's Portfolio

My personal portfolio for Rutgers Business School's Building Your Brand course.

**Website:** https://ya360-hash.github.io/

## What's included

- A one-sentence personal statement
- Skills in finance, research tools, and business operations
- Three projects: a Home Depot stock pitch, the NovaCure commercialization case, and website and operations improvements at Masala Bay
- Education, work experience, and project references in my résumé overview

Project summaries come from my résumé. The original presentations and project files are not included. Each project links to its entry in the résumé overview.

## Website setup

The public repository is named `ya360-hash.github.io`. GitHub Pages publishes `index.html` from the root of the `main` branch. The page contains its own styles and scripts, so no installation or build tools are needed.

To update the portfolio, edit `index.html` and commit the changes to `main`. GitHub Pages will publish the update automatically.
